# Tarian Ventures Brand Pack

This package contains production-oriented vector brand assets and the V1 website implementation specification.

## Structure
- `logos/` — primary SVG logo variants
- `icons/` — favicon/app icon variants
- `guidance/BRAND_GUIDELINES.md`
- `guidance/ASSET_PROVENANCE.md`
- `guidance/CODEX_WEBSITE_IMPLEMENTATION_SPEC.md`

The SVG artwork is clean deterministic vector geometry created from the approved Concept 1 direction. Before trademark registration, large-format print production, or permanent signage, consider a final specialist vector/brand review.
